# Getting Started / Erste Schritte

## English

### What is CRANIX Mobile App?

CRANIX Mobile App is a Progressive Web App (PWA) for administering school IT infrastructure. It provides a unified interface for:

- **Cephalix Mode**: Multi-school management (for service providers)
- **Cranix Mode**: Single-school administration (for school IT admins)
- **Education Module**: Teaching tools (lessons, tests, challenges)
- **Trusted Pages**: Public registration forms (no login required)

### System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection to CRANIX server
- Valid user account with appropriate permissions

### Accessing the App

1. Open your browser and navigate to your CRANIX server URL
   - Example: `https://cranix.your-school.org`
2. You will be redirected to the login page automatically
3. For PWA installation: Use browser's "Install App" feature

### First Login

1. Enter your **username** and **password**
2. Select your **institute** from the dropdown (if multiple)
3. Click **Login**
4. If 2FA is enabled: Enter the PIN sent to your device
5. You'll be redirected to your default landing page based on your role

### Browser Compatibility

| Browser | Minimum Version | PWA Support |
|---------|----------------|-------------|
| Chrome | 90+ | Full |
| Firefox | 88+ | Full |
| Safari | 14+ | Full (iOS 14.3+) |
| Edge | 90+ | Full |

### Offline Capabilities

As a PWA, the app caches resources for offline use. However, **all administrative actions require an active connection** to the CRANIX server.

### Language Selection

The app supports **English** and **German**. Language is detected from browser settings or can be changed in:
- **Profile → Myself → Language**

## Deutsch

### Was ist die CRANIX Mobile App?

Die CRANIX Mobile App ist eine Progressive Web App (PWA) zur Verwaltung der schulischen IT-Infrastruktur. Sie bietet eine einheitliche Oberfläche für:

- **Cephalix-Modus**: Multi-Schul-Verwaltung (für Dienstleister)
- **Cranix-Modus**: Einzelschul-Administration (für Schul-IT-Admins)
- **Bildungsmodul**: Unterrichtstools (Lektionen, Tests, Challenges)
- **Vertrauenswürdige Seiten**: Öffentliche Anmeldeformulare (kein Login erforderlich)

### Systemvoraussetzungen

- Moderner Webbrowser (Chrome, Firefox, Safari, Edge)
- Internetverbindung zum CRANIX-Server
- Gültiges Benutzerkonto mit entsprechenden Berechtigungen

### Zugriff auf die App

1. Öffnen Sie Ihren Browser und navigieren Sie zu Ihrer CRANIX-Server-URL
   - Beispiel: `https://cranix.ihre-schule.org`
2. Sie werden automatisch zur Anmeldeseite weitergeleitet
3. Für PWA-Installation: Nutzen Sie die "App installieren"-Funktion des Browsers

### Erste Anmeldung

1. Geben Sie **Benutzername** und **Passwort** ein
2. Wählen Sie Ihr **Institut** aus dem Dropdown-Menü (falls mehrere)
3. Klicken Sie auf **Anmelden**
4. Falls 2FA aktiviert: Geben Sie den an Ihr Gerät gesendeten PIN ein
5. Sie werden basierend auf Ihrer Rolle zur Standard-Startseite weitergeleitet

### Browser-Kompatibilität

| Browser | Mindestversion | PWA-Unterstützung |
|---------|---------------|-------------------|
| Chrome | 90+ | Vollständig |
| Firefox | 88+ | Vollständig |
| Safari | 14+ | Vollständig (iOS 14.3+) |
| Edge | 90+ | Vollständig |

### Offline-Fähigkeiten

Als PWA cached die App Ressourcen für die Offline-Nutzung. **Alle administrativen Aktionen erfordern jedoch eine aktive Verbindung** zum CRANIX-Server.

### Sprachauswahl

Die App unterstützt **Deutsch** und **Englisch**. Die Sprache wird aus den Browsereinstellungen erkannt oder kann geändert werden in:
- **Profil → Selbst → Sprache**
