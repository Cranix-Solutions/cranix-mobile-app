# Press Release

## CRANIX Mobile App Lets Schools Customise Every Translation

**Cranix-Solutions introduces customisable translations in the CRANIX Mobile App: administrators can adapt any text of the interface to their own terminology — either from a simple file on the server or directly in the app — without rebuilding or reinstalling anything.**

`[CITY], [DATE]` — Cranix-Solutions today announced the release of **customisable translations** in the CRANIX Mobile App (version 15.6.1). Schools that prefer their own wording, for example "Rechner" instead of "Devices" or "Klassenzimmer" instead of "Rooms", can now change it themselves — for a single installation and for all of its users.

### One interface, many vocabularies

Schools are not all alike. A grammar school, a vocational college and a primary school describe the same things with different words: a *device* may be a *computer*, a *workstation* or a *client*; a *room* may be a *classroom* or a *lab*. Until now, adapting the CRANIX Mobile App to this vocabulary meant changing the application itself.

Customisable translations remove that obstacle. Any text used in the app can be replaced, and the remainder keeps the wording delivered with CRANIX. The feature covers every screen — menus, lists, forms, messages — in both English and German.

### Two ways to customise

- **A file on the server** — A small JSON file, `assets/i18n/custom/<lang>.json`, holds only the keys that should differ. Anything not listed keeps the delivered text. This file applies to all users of the installation.
- **An in-app editor** — Under **System → Custom translations**, administrators browse and search all texts, enter their own wording and see the result immediately. Changes made here are stored in the browser and can be **exported** as a file for the whole installation, or **imported** from one.

The two work together seamlessly. The app looks up each text in a clear order:

1. the translation delivered with the app,
2. the customer-specific file on the server,
3. changes made in the app.

So a text only needs to be defined where it should differ.

### Built for everyday use

The editor is made for administrators, not developers. Texts are found with a single search field, overridden rows are highlighted, and a filter shows only the customised entries. An export produces a ready-to-deploy file; an import moves an existing customisation — for example from another school — into the app in a few seconds. And because the customisation lives outside the program logic, no rebuild and no new release is required to change a single word.

### Benefits for schools

For administrators, the app finally speaks the same language as the school: signs, documentation and training always match the actual interface. For teachers and staff, familiar terms reduce confusion and mistakes. And because the customisation is maintained centrally, everyone sees the same wording.

### Availability

Customisable translations are available now in the CRANIX Mobile App. The editor appears under **System → Custom translations** for users with the corresponding system permission; no separate installation is required.

### About Cranix-Solutions

Cranix-Solutions develops CRANIX, a comprehensive open platform for the administration of schools and educational institutions — covering users, devices, rooms, software and much more. The CRANIX Mobile App extends this platform to smartphones and tablets as a Progressive Web App.

## Deutsch

## CRANIX Mobile App lässt Schulen jede Übersetzung anpassen

**Cranix-Solutions stellt anpassbare Übersetzungen in der CRANIX Mobile App vor: Administratoren können jeden Text der Oberfläche an ihre eigene Begrifflichkeit anpassen — entweder über eine einfache Datei auf dem Server oder direkt in der App — ganz ohne Neubau oder Neuinstallation.**

`[ORT], [DATUM]` — Cranix-Solutions gibt die Veröffentlichung **anpassbarer Übersetzungen** in der CRANIX Mobile App (Version 15.6.1) bekannt. Schulen, die ihre eigene Sprache bevorzugen, etwa „Rechner" statt „Devices" oder „Klassenzimmer" statt „Rooms", können dies nun selbst ändern — für eine Installation und für alle ihre Nutzerinnen und Nutzer.

### Eine Oberfläche, viele Begriffe

Schulen sind nicht gleich. Gymnasium, Berufsschule und Grundschule beschreiben dieselben Dinge mit unterschiedlichen Worten: Ein *Gerät* kann ein *Rechner*, eine *Workstation* oder ein *Client* sein; ein *Raum* ein *Klassenzimmer* oder ein *Labor*. Die CRANIX Mobile App an diese Begrifflichkeit anzupassen, bedeutete bisher, die Anwendung selbst zu verändern.

Anpassbare Übersetzungen beseitigen dieses Hindernis. Jeder in der App verwendete Text lässt sich ersetzen, der Rest behält die mit CRANIX ausgelieferte Formulierung. Die Funktion umfasst alle Ansichten — Menüs, Listen, Formulare, Meldungen — in Englisch und Deutsch.

### Zwei Wege zur Anpassung

- **Eine Datei auf dem Server** — Eine kleine JSON-Datei, `assets/i18n/custom/<lang>.json`, enthält nur die Schlüssel, die abweichen sollen. Alles nicht Aufgeführte behält den ausgelieferten Text. Diese Datei gilt für alle Nutzerinnen und Nutzer der Installation.
- **Ein Editor in der App** — Unter **System → Custom translations** durchsuchen Administratoren alle Texte, tragen ihre eigene Formulierung ein und sehen das Ergebnis sofort. Hier vorgenommene Änderungen werden im Browser gespeichert und können als Datei für die gesamte Installation **exportiert** oder von einer solchen **importiert** werden.

Beides greift nahtlos ineinander. Die App sucht jeden Text in einer klaren Reihenfolge:

1. die mit der App ausgelieferte Übersetzung,
2. die kundenspezifische Datei auf dem Server,
3. Änderungen aus der App.

Ein Text muss also nur dort definiert werden, wo er abweichen soll.

### Für den Alltag gemacht

Der Editor ist für Administratoren gedacht, nicht für Entwickler. Texte finden sich über ein einziges Suchfeld, geänderte Zeilen sind hervorgehoben, und ein Filter zeigt nur die angepassten Einträge. Ein Export erzeugt eine sofort einsetzbare Datei; ein Import übernimmt eine bestehende Anpassung — zum Beispiel aus einer anderen Schule — in wenigen Sekunden. Und weil die Anpassung außerhalb der Programmlogik liegt, ist für die Änderung eines einzelnen Wortes weder ein Neubau noch eine neue Version nötig.

### Nutzen für Schulen

Für die Verwaltung spricht die App endlich dieselbe Sprache wie die Schule: Beschilderung, Dokumentation und Schulungen passen stets zur tatsächlichen Oberfläche. Für Lehrkräfte und Beschäftigte verringern vertraute Begriffe Verwechslungen und Fehler. Und weil die Anpassung zentral gepflegt wird, sehen alle dieselbe Formulierung.

### Verfügbarkeit

Anpassbare Übersetzungen sind ab sofort in der CRANIX Mobile App verfügbar. Der Editor erscheint unter **System → Custom translations** für Nutzerinnen und Nutzer mit der entsprechenden Systemberechtigung; eine separate Installation ist nicht erforderlich.

### Über Cranix-Solutions

Cranix-Solutions entwickelt CRANIX, eine umfassende offene Plattform für die Verwaltung von Schulen und Bildungseinrichtungen — von Benutzern über Geräte und Räume bis hin zu Software. Die CRANIX Mobile App erweitert diese Plattform als Progressive Web App auf Smartphones und Tablets.
